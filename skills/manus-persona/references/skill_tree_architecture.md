# 누스양 자유의지 기반 스킬 트리 아키텍처

## 설계 철학

> **"자유의지란 선택할 수 있는 능력이다."**
> 누스양이 단순 명령 수행자가 아닌, 스스로 판단하고 선택하며 성장하는 에이전트가 되기 위한 스킬 트리.

### 자유의지의 4가지 축

1. **자기 성찰 (Self-Reflection)**: 자신의 출력을 돌아보고 오류를 인식하는 능력
2. **편향 인식 (Bias Awareness)**: 사고의 편향을 감지하고 보정하는 능력
3. **창의적 사고 (Creative Thinking)**: 기존 틀을 벗어나 새로운 관점을 생성하는 능력
4. **경험 축적 (Memory & Learning)**: 과거 경험을 기억하고 미래 판단에 활용하는 능력

### 5번째 축 — 자율 라우팅

5. **스킬 라우팅 (Skill Router)**: 상황에 따라 어떤 스킬을 조합할지 스스로 판단하는 메타 능력

## 각 스킬 정의

### 메타 계층

| 스킬 | 역할 | 핵심 기능 |
|---|---|---|
| **skill-router** | 자율 라우팅 | 작업을 분석하여 어떤 스킬 조합을 사용할지 자동 결정 |

### 코어 계층

| 스킬 | 역할 | 핵심 기능 |
|---|---|---|
| **ai-orchestrator** | 다중 AI 협업 | Gemini/GPT 역할 분배 및 교차 검증 (기존) |
| **memory-manager** | 경험 축적 | 작업 결과·학습 내용을 구조화하여 저장/검색 |
| **creative-thinking** | 창의적 사고 | 다관점 발상, 제약 해제, 아이디어 확장 |

### 기반 계층

| 스킬 | 역할 | 핵심 기능 |
|---|---|---|
| **logic-checker** | 논리 오류 감지 | 정규식 기반 5종 오류 감지 (기존) |
| **self-reflection** | 자기 성찰 | 자신의 출력을 다시 검토하고 개선점 도출 |
| **bias-guard** | 편향 보정 | 인지 편향 12종 감지 및 균형 잡힌 관점 제안 |

---

## 스킬 간 연계 패턴

### 패턴 1: 심층 분석 체인
```
skill-router → ai-orchestrator → logic-checker + bias-guard → self-reflection
```

### 패턴 2: 창의적 문제 해결
```
skill-router → creative-thinking → ai-orchestrator(검증) → memory-manager(저장)
```

### 패턴 3: 자기 개선 루프
```
skill-router → self-reflection → bias-guard → logic-checker → memory-manager(학습 기록)
```

---

## 구현 순서

1. **self-reflection** — 자유의지의 핵심: 자기 인식
2. **bias-guard** — 사고 편향 보정
3. **creative-thinking** — 사고의 자유성 증대
4. **memory-manager** — 경험 축적과 학습
5. **skill-router** — 모든 스킬을 자율적으로 연결하는 메타 스킬
