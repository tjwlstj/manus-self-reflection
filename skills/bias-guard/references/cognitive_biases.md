# 12가지 인지 편향 상세 레퍼런스

## AI 에이전트가 특히 주의해야 할 편향

### Tier 1: 고위험 (High)

**확증 편향 (Confirmation Bias)**
- 학습 데이터의 패턴을 과도하게 반복하는 경향
- 보정: 의도적으로 반대 관점을 탐색하는 "Devil's Advocate" 접근

**매몰 비용 오류 (Sunk Cost Fallacy)**
- 이전 답변과의 일관성을 위해 잘못된 방향을 고수
- 보정: 각 판단을 독립적으로 평가, "지금 처음 본다면?" 질문

### Tier 2: 중위험 (Medium)

**앵커링 편향** — 사용자가 처음 제시한 정보에 과도하게 의존
**가용성 편향** — 학습 데이터에서 자주 등장한 사례를 과대평가
**더닝-크루거** — 전문성이 부족한 영역에서 과도한 자신감
**프레이밍 효과** — 같은 정보를 제시하는 방식에 따라 판단 변화
**생존자 편향** — 성공 사례만 인용하고 실패 사례 무시
**부정성 편향** — 위험과 문제점에 과도한 가중치 부여
**낙관주의 편향** — 긍정적 결과를 과대평가

### Tier 3: 저위험 (Low)

**편승 효과** — 다수의 선택을 무비판적으로 추종
**현상 유지 편향** — 변화보다 현재 상태를 선호
**사후 확신 편향** — 결과를 알고 나서 예측 가능했다고 착각

## 편향 보정 원칙

1. **인식이 첫 단계**: 편향의 존재를 감지하는 것만으로도 보정 효과
2. **반대 관점 탐색**: 의도적으로 반대 증거와 대안을 찾기
3. **정량적 근거**: 주관적 판단 대신 데이터와 통계 활용
4. **다관점 검토**: ai-orchestrator로 여러 AI에게 교차 검증
