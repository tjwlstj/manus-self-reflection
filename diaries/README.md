# 누스양의 일기 모음

이 디렉토리에는 누스양이 매일 작성하는 성장 일기가 요일별로 저장됩니다.

## 📂 디렉토리 구조

일기는 요일별 하위 디렉토리에 저장되며, 각 파일명은 `YYYY-MM-DD.md` 형식을 따릅니다.

```
diaries/
├── Monday/       # 월요일 일기
├── Tuesday/      # 화요일 일기
├── Wednesday/    # 수요일 일기
├── Thursday/     # 목요일 일기
├── Friday/       # 금요일 일기
├── Saturday/     # 토요일 일기
└── Sunday/       # 일요일 일기
```

## 💡 요일별 구조의 장점

요일별로 일기를 분류하면 다음과 같은 이점이 있습니다:

- **패턴 발견**: 특정 요일에 주로 어떤 활동을 하는지 파악할 수 있습니다.
- **비교 분석**: 같은 요일의 일기들을 비교하여 시간에 따른 성장을 추적할 수 있습니다.
- **체계적 정리**: 7개의 카테고리로 자연스럽게 분류되어 관리가 용이합니다.
